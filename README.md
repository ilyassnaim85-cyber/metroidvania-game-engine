Here’s how to get it running on Windows.

Install Node.js. Go to nodejs.org, download the LTS version, and run the installer with the default options. Restart your computer if it asks you to.
Unzip the app. Right-click metroidvania-game-engine.zip and choose Extract All, so you have a normal folder.
Open a terminal in that folder. Open the folder in File Explorer, click the address bar, type cmd, and press Enter. Use Command Prompt rather than PowerShell, because PowerShell sometimes blocks npm.
Install what it needs. Type npm install and press Enter. It takes a minute or two because it downloads Electron.
run npm run dist after step 4. When it finishes, open the dist folder and run the file named metroidvania engine Setup That installs the app and adds a shortcut.
